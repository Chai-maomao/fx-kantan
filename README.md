# FX kantan!

娱乐型外汇模拟交易网页，使用 [BiQuote](https://biquote.io/docs/) 提供的实时外汇买卖报价和 OHLC 图表。所有资金、订单及盈亏都是虚拟的，不会连接真实交易账户。

## 使用

打开已发布的网站即可游玩。若要在本地预览，先运行 `npm install`、`npm run db:generate`（已有迁移时可跳过），再运行 `npm run dev`；本地预览会在内存数据库中运行排行榜。

## GitHub Pages 镜像

静态页面会从仓库 `main` 分支的 `dist/` 目录自动部署到 [GitHub Pages 镜像](https://chai-maomao.github.io/fx-kantan/)。模拟交易、图表及个人记录在浏览器内运行；镜像的公开排行榜通过跨域 API 连接主站 `fx-kantan.top`，匿名身份保存在镜像站的浏览器本地数据中，因此同一浏览器在两个域名上会有各自的榜单记录。GitHub Pages 不运行 Worker 或 D1；主站 API 或 BiQuote 行情无法连接时，相关功能也会受影响。镜像网址在中国大陆不同网络的可达性需要实际测试，不能仅凭托管在 GitHub Pages 就保证。

从 14 个主流与日元相关货币对中选择品种，切换 K 线或分时线，并选择周期与跨度，包括 1 分钟周期和近 1 小时的组合。电脑端可悬停查看往时 K 线开、高、低、收价格，使用滚轮缩放，缩放后按住鼠标拖动浏览历史。下单填写美元保证金并选择杠杆，显示预计仓位金额和买卖对应的基础货币数量；数量按整单位向下取整，实际占用保证金不超过输入金额。用户可设置新仓的止盈止损价格，也可修改已有仓位；达到目标价时，网页在收到新行情后按当时买卖价模拟平仓。页面关闭期间不会监控或触发止盈止损。新账户及重置后的账户默认 100,000 美元，杠杆最高 500 倍（新增 200、300、500 倍）；已有账户保留原资金和盈亏基准；调整杠杆只影响后续新仓的保证金。行情关闭、过期或连接失败时交易按钮会停用。

止盈止损输入框会以淡色显示当前参考价，点击数字框箭头或手动输入后才会启用该价格；未改动的参考价不会自动设为止盈止损。日元货币对按 0.001、其他货币对按 0.00001 调整。持仓的平仓按钮在行情更新时保持稳定；报价暂不可用时点击会解释原因，成交仍以最新有效报价为准。

账户、持仓与交易记录只保存在当前浏览器。更换设备、清除浏览器数据或使用无痕模式会失去记录。用户可以自愿把展示名、账户总盈亏以及最近 20 条交易记录快照发布到公开盈亏榜；点击榜单玩家可展开查看其交易记录。发布后的快照保存在站点数据库，同一浏览器再次发布会覆盖之前的记录，也可以撤下。浏览器使用匿名 Cookie 识别自己的记录，不要求注册账号；清除 Cookie 后会失去旧记录的管理权。旧版排行榜记录没有交易历史，需由原发布者重新发布才会出现。排行榜不做身份或反作弊验证，也不会随本地交易自动更新。

## 技术说明

前端为 HTML、CSS、JavaScript，站点 Worker 提供静态资源与排行榜 API，排行榜使用 D1。分时线按所选 OHLC 周期的收盘价绘制，当前周期随最新 Tick 更新；图表每 20 秒与服务端同步。开仓以 `ask` 买入或 `bid` 卖出，平仓采用相反报价。做多止盈止损按 `bid` 判断，做空按 `ask` 判断；发生跳空时以触发后收到的当前价结算。非美元报价的持仓盈亏按相应 USD 货币对的最新中间价换算为美元。网页只供娱乐，不代表可成交的真实市场价格。

强平采用单仓保证金规则：浮亏达到该仓保证金时，按有效报价自动强制平仓。下单区与持仓表显示参考强平价；美元作为基础货币时包含换算价格变化，其他交叉盘按当前美元换算汇率估算。跳价可能超过保证金，关闭页面期间不监控；历史仓位同样适用。
